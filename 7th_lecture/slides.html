Recap: closed, open-weight, open-source

“Open” is used loosely. What matters is what you actually get to download.

you get: an API
+ the trained weights
+ training code and data

Closed

GPT · Claude · Gemini

an API and a chat app

the model — it runs on their servers, and your data goes there

control — versions change or get retired under you

Open-weight

Qwen · DeepSeek · Kimi · GLM · Mistral · Gemma · gpt-oss · Llama

the trained weights — run, quantize, fine-tune anywhere

training data and code — you can run it, not rebuild it

Licences vary: Apache 2.0 / MIT, or custom ones with restrictions (Llama, Gemma).

Open-source

OLMo (Ai2) · Pythia (EleutherAI)

weights + training code + data — reproducible from scratch

rare, and behind the best open-weight models

Most “open-source LLMs” in the news are really open-weight.

Why run open models

  • data never leaves your machine
  • projects under NDA that forbid cloud AI
  • fixed version → reproducible results
  • no price per token
  • works offline and on HPC nodes

The cost

  • you need the hardware
  • you do the setup and the updates
  • usually behind the best closed models

Running it yourself: Ollama + Open WebUI

Two free tools turn a downloaded model into your own ChatGPT.

  • Ollama — downloads and runs open-weight models, on CPU, NVIDIA, AMD or Apple silicon
    • install — Linux: curl -fsSL https://ollama.com/install.sh | sh
      macOS / Windows: installer from ollama.com/download
    • ollama pull qwen3.5  →  ollama run qwen3.5
    • models, already quantized: ollama.com/search
    • API on localhost:11434 for Python, VS Code, Open WebUI
  • Open WebUI — a ChatGPT-style web interface on top of Ollama
    • chat history, documents, web search, multiple users
    • runs as a Docker container (or pip install open-webui)
    • point it at Ollama, open localhost:3000 in the browser

eInfra models in VS Code

eInfra runs the big open-weight models for Czech academia. Copilot can use them as a custom endpoint.

  1. Get an API key:  chat.ai.e-infra.cz → Settings → Account → API Keys
  2. Add the endpoint:  Copilot Chat → model picker → Manage Models → Add Models… → Custom Endpoint; name it eInfra, paste the key
  3. Fill in the models:  VS Code opens chatLanguageModels.json — keep its apiKey line, add one entry per model (right)
  4. Use it:  the models appear on their own eInfra tab in the model picker
  • id must match the server exactly — list them at llm.ai.e-infra.cz/v1/models (with your key)
  • vision, thinking, token limits — from the model card; too high a limit and long chats fail
  • Status of all models: llm.ai.e-infra.cz/status
  • Your usage: llm.ai.e-infra.cz/usage
